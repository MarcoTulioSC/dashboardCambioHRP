# dashboardCambioHRP

Dashboard feito através de dados buscados pelo banco BNA de Angola(colocados em planilha excel) para controle de compras e exportações de mercadorias das empresas, com moedas como dolar, euro e real.
Pequeno site utilizando js, html e css, com tela de carregamento interativa e, por fim, a tela de dashboard com os gráficos feitos no power bi, sendo usado modelo matemático de arima para prever a quantidade da moeda no dia seguinte(feito em python).
